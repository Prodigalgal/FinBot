## 宏观事件接入方案

### 优先覆盖

| 地区 | 第一批指标 | 后续扩展 |
|---|---|---|
| 美国 | 非农就业变化、失业率、劳动参与率、平均时薪、初请/续请失业金、JOLTS、CPI/核心 CPI、PCE/核心 PCE | GDP、零售销售、FOMC 决议及纪要 |
| 中国 | 城镇调查失业率、CPI/PPI、官方 PMI、GDP、工业增加值、社会消费品零售、固定资产投资 | 社融、人民币贷款、M2、LPR 与其他政策发布 |

发布日历和公布值分别采集。美国采用 [BLS 官方日历](https://www.bls.gov/schedule/2026/home.htm)、[BEA 发布安排](https://www.bea.gov/news/schedule) 等发布机构的一手渠道。中国优先采用[国家统计局发布日程与新闻稿](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)；其说明指出数据发布库全部进度指标可能晚约三个工作日更新，因此数据库接口不能代替发布时点的新闻稿采集。

不硬编码“每月第一个周五”等推算规则。美国日历时间为 Eastern Time，使用 `America/New_York` 转 UTC；中国使用 `Asia/Shanghai`。日程调整、春节合并发布、延期和取消必须保存来源及变更记录。

### 建议的最小数据契约

1. **指标定义**：`indicator_id`、国家、发布机构、统计口径、单位、频率、季调标志、数据源、与标的的相关性规则。美国非农、美国失业率、中国城镇调查失业率使用不同指标 ID，不把它们合并成一个就业数值。
2. **发布事件**：`event_id`、发布时间、原始时区、统计期间、发布状态、关联指标和来源 URL。同一份就业报告关联多个指标，避免把非农、时薪和失业率重复计成三个独立信息源。
3. **观测版本**：原始公布值、当时前值、修订前值、修订后值、首次公布/修订标记、官方发布时间、首次抓到时间、抓取时间、内容 hash、原文证据 ID。以发布事件和指标组成幂等键，数值变更追加版本。
4. **市场预期快照**：预期值、提供方、样本口径、快照时间、抓取时间。来源不可靠或没有可用授权时保存空值；AI 自己的预测单独保存，不冒充市场一致预期。
5. **研究快照**：`as_of`、事件 ID、观测版本 ID、预期快照 ID、待公布事件及缺失原因。所有席位接收同一版本的结构化事实。

数据可用时间与统计期间必须分开。历史评估按当时可获得的版本取值，禁止用事后修订的最新数据回填旧研究。[FRED 实时期间说明](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html)展示了按历史可知时点检索信息的边界；对没有历史发布版本的来源，明确标记无法进行可信的当时回放。

### 接入现有流程

沿用 ingestion 的来源、抓取重试和原文证据；新增独立的发布事件/观测读取模型，经确定性校验后进入冻结研究上下文。宏观事实不受通用新闻 `DOCUMENT_LIMIT=12` 排序挤占，新闻压缩包用于补充解读。

研究前展示即将公布的相关事件；发布后展示原值、修订和预期差（预期缺失时不计算）。事件触发只请求重新分析，不直接创建订单。后续模拟执行仍经过既有共识和硬风控。

验收覆盖：冬夏令时、日程调整、延期、取消、重复抓取、多个指标同一事件、单位/季调校验、缺预期值、历史修订、标的相关性、数据未发布时不得填入实际值、刷新与重启后恢复。

## 本轮角色模型调整

用户最终确认：一个角色可以多个席位，同一角色内避免复用模型，角色之间可以复用。默认保留五角色、每角色两席位：

| 角色 | 主模型组合 | 两席位的 fallback 组合 |
|---|---|---|
| 证据分析 | MiMo v2.5 / GLM 5.3 | LongCat Pro / MiniMax M3.1 Flash Preview |
| 看多分析 | LongCat Pro / Grok 3 | MiMo v2.5 / GLM 5.3 |
| 看空分析 | GLM 5.3 / MiniMax M3.1 Flash Preview | Grok 3 / LongCat Pro |
| 市场结构 | Grok 3 / MiMo v2.5 | GLM 5.3 / MiniMax M3.1 Flash Preview |
| 风险控制 | MiniMax M3.1 Flash Preview / LongCat Pro | Grok 3 / MiMo v2.5 |

同一角色的四个可选模型不同。每个角色仍只有一份总投票权重，保留原有最低参与席位 5、最低投票角色 3、阶段超时与预算。

五个模型均通过短文本流式推理及终态验证。Grok 3 拒绝 `reasoning_effort=high`，改为 `PROVIDER_DEFAULT`，其余保持 HIGH。Grok 和 MiniMax 还拒绝 `max_tokens`，两个模型配置的 `tokenLimitParameterStyle` 改为 `NONE`；工作流的内部预算和截止时间保留，但上游不接受输出 Token 限额，不能把预算估算视为上游硬限制。DeepSeek 的 `default/expert` 为不透明路由选择器，未选作本轮要求显式模型身份的研究席位；既有采集清洗/压缩节点未调整。

经 FinBot 认证节点诊断和 `ai_invocation` 实际模型身份核对，五个主模型均 COMPLETED。初次 Grok 节点虽 COMPLETED，实际是 GLM fallback；MiniMax 初次失败。参数修正后仅复测这两个节点，均由请求的主模型完成。节点测试没有启动完整 SDB-SCA 辩论，也没有订单。

新版本 `workflowversion_00000mus8minn_0afdd98a3f1bb8c99d4c`（v15），原版本 v14 留存。模型目录和短推理通过只证明可调用；节点诊断或完整研究需分别记录结果，不能据此宣称决策有效。

## 决策有效性的判断与优化

### 最近一次平票的可观测问题

读取该决策持久化的 10 张完整选票，包含 5 个席位、3 个角色、8 个候选，每个角色有 28 个候选对。

- 看多角色两席位相反意见导致正序 3 对、逆序 2 对弃权；市场结构角色对应为 5 对、1 对。
- 5 个席位中，4 个席位的正反序偏好存在变化，分别为 2、3、3、7 个候选对。
- 显式并列、同角色意见冲突、席位失败和排序变化分别计数。一次正反序差异不能区分位置偏差与生成随机性，也不能证明市场判断错误。

模型异构是合理优化方向，但不能用提高 SELECTED 比例作为唯一目标。保留真实分歧和“不采取行动”能提供有价值的信息。增加席位不能增加角色权重，也不应为了消除平票而强行增加第三席位或降低 quorum。

### 评估三类问题

| 问题 | 指标与方法 |
|---|---|
| 工程能否可靠完成 | 各阶段完成率、角色覆盖、主模型/fallback 实际身份、错误类型、终态收敛、耗时、Token 和未知价格的标记 |
| 辩论是否增加信息 | 相同样本上比较提案与修正版的事实准确性、证据完整性、预测分数、错误修正及错误传播；跟踪同角色分歧、正反序稳定性与模型错误相关性 |
| 最终决策是否有用 | 事先定义 horizon、客观 UP/SIDEWAYS/DOWN 标签、Brier/log loss、校准、区间覆盖与宽度、弃权覆盖率、扣手续费/滑点/资金费后的模拟收益和回撤 |

当前 SIDEWAYS 方向正确性按模型自己给出的区间判定，与 UP/DOWN 的零收益分界不等价；影子收益没有扣除成本。应先统一标签和评估口径，再比较方法。胜出论证与所有角色聚合出的数值预测也须分别呈现并校验一致性。

### 对照实验

采用同一标的、同一冻结证据/宏观观测版本、同一预测期限和预先固定的评估规则，比较：

1. 强单模型分析及其重复采样聚合。
2. 独立多模型提案与角色归一聚合。
3. 当前完整 SDB-SCA：独立提案、匿名评审、隔离修正、正反序 Schulze。

分别按 Token 预算和响应时间预算比较，不把调用数相同等同于预算相同。统计所有开始的案例，失败与弃权进入覆盖率，避免只统计成功案例。不同标的在同一非农事件附近的案例按事件/时间分组，避免把同一次冲击当成多个独立样本。

先以 30–50 个前瞻性纯分析案例验证数据与评价流程，再按实际效应和波动估计正式样本量。历史回放适合排查实现，但模型参数可能已包含历史事件信息，冻结提示词不能单独排除这种泄漏；前瞻性留出样本优先。

[模型异构与辩论评估研究](https://arxiv.org/abs/2502.08788)和[辩论与投票对照研究](https://arxiv.org/abs/2508.17536)说明需要强单模型、独立投票与预算对齐的基线。它们的通用任务结果不能作为 FinBot 的预测或盈利证明。

### 推进顺序

1. 整理模拟盘账户同步、遗留 RUNNING 和失败终态。
2. 实现宏观事件契约及标的相关性/正文质量门禁。
3. 使用 v15 在纯分析范围跑通完整面板，并持续收集对照样本。
4. 数据足够后按客观指标决定是否保留评审、调整席位、缩减低收益调用或扩大模拟执行。实盘授权另行处理。
